# **App Name**: Nextfolio

## Core Features:

- Project Showcase: Display featured projects with descriptions, images, and links to live demos or GitHub repositories.
- About Me Section: A dedicated section for a personal introduction, skills overview, and experience summary.
- Contact Form: Allow visitors to send direct messages, with fields for name, email, and message.
- Skill Assessment: An AI tool that determines what the optimal project arrangement is to showcase relevant skills based on portfolio descriptions.

## Style Guidelines:

- Primary color: Dark slate blue (#434E5F), reflecting sophistication and tech.
- Background color: Very light gray (#F7F7F7), for a clean, modern feel.
- Accent color: Sky blue (#77C4D9) to provide subtle but lively highlights and call to actions.
- Body and headline font: 'Inter', a sans-serif font to ensure readability and a modern feel.
- Minimal, line-based icons for skills, technologies, and navigation elements, in a matching primary color.
- Clean, grid-based layout inspired by modern design principles, optimized for responsiveness across devices.
- Subtle animations for transitions and interactive elements to add polish without overwhelming the user.
